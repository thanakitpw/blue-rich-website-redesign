## How it was loaded (one-off)

The Supabase CLI wasn't logged in and the batch SQL (~300 KB) was too big for the MCP. A
temporary `security definer` RPC `public.tmp_blog_import_20261026(token, rows, remove_slugs)`,
guarded by a random token, was created through MCP `execute_sql` and called once from a local
script with the anon key. It was dropped straight after; `pg_proc` was checked and no
`tmp_blog_import%` function remains. Prefer `supabase db query --linked -f` next time. Only
reuse the temporary RPC if the CLI is unavailable, and always drop it in the same session.
