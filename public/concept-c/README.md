# Concept C — หน้าตาแบบ B แต่จัดเลย์เอาต์ใหม่

> เวอร์ชันแรกของ C เป็นแนว "เอกสารเทคนิค" (เส้นบาง มุมเหลี่ยม โทนกระดาษ)
> ลูกค้าไม่ชอบ จึงเขียนใหม่ทั้งไฟล์ — **ใช้ design system ชุดเดียวกับ Concept B**
> (โทนน้ำเงิน-ฟ้า + ส้ม การ์ดมุมมน เงานุ่ม ฟอนต์ Prompt) แต่ **จัดวางใหม่ทุก section**

ไฟล์เดียวจบ: `index.html` — เปิดที่ `http://localhost:8899/concept-c/index.html`

## B กับ C ต่างกันตรงไหน

หน้าตา (สี ปุ่ม การ์ด ความมน ฟอนต์) **เหมือนกัน** ต่างกันที่โครงหน้า

| | Concept B | Concept C |
|---|---|---|
| Header | 2 แถว (utility bar + เมนู) | **แถวเดียว** + announce bar น้ำเงินด้านบน |
| เปิดหน้า | **สไลด์แบนเนอร์ 3 ภาพ** สูง 550px มุมมนอยู่ในคอนเทนเนอร์ | **ภาพเดียวเต็มความกว้างจอ** สูง 520px ไม่มีมุมมน ไม่มีสไลด์ |
| ใต้แบนเนอร์ | H1 กลางหน้า + การ์ดหมวดใหญ่ 2 ใบ | **บล็อกแนะนำจัดกลาง** — eyebrow / H1 / คำโปรย / ปุ่ม / ชิปมาตรฐาน |
| ใต้ hero | แถบจุดเด่น 4 ช่องพื้นฟ้าอ่อน | **การ์ดทางเข้า 3 ใบ** (สีกันไฟ / ผ้ากันไฟ+ซีเมนต์ / งานรับรอง) มีไอคอน + ลิงก์ |
| สินค้า | การ์ดเรือธงใหญ่ซ้าย + กริดขวา | **ไซด์บาร์หมวดแบบ sticky (มีจำนวนสินค้า) + กริด 3 คอลัมน์** กรองได้จริง + กล่อง "ไม่แน่ใจว่าใช้ตัวไหน" |
| สถิติ | อยู่ในแถบ about | **แถบน้ำเงินเข้มลอยคร่อมรอยต่อ section** |
| ระบบสีกันไฟ | ไม่มี | **การ์ด 3 ใบเรียง มีเลข 1-2-3 + เส้นประเชื่อม + กล่องหมายเหตุ** |
| ทำไมต้องเลือกเรา | ไม่มีแยก | **ภาพคลังสินค้าซ้าย + 4 จุดแข็งแบบ 2×2 ขวา** |
| ผลงาน | bento 4×4 | **กริด 3 คอลัมน์ ใบแรกใหญ่ 2×2 + caption ทับภาพ** |
| งานรับรอง | รูป + ลิสต์ธรรมดา | **แผงพื้นฟ้ามุมมนใหญ่** ภาพซ้าย + เอกสาร 6 ชุดเป็นการ์ด 2 คอลัมน์ |
| บทความ | การ์ด 3 ใบเท่ากัน | **1 ใบเด่นใหญ่ + 3 ใบเล็กแนวนอน** |
| FAQ | หัวข้อซ้าย + accordion ขวา | **accordion 2 คอลัมน์เต็มความกว้าง** |
| CTA | แถบธรรมดา | **แผงน้ำเงินเข้มมุมมน มีวงแหวนตกแต่ง จัดกลาง** |

## ปรับตามฟีดแบ็กลูกค้า (รอบ "เปิดมาอย่าขายของ")

เดิม hero เป็นแบบแยกซ้าย-ขวา (ข้อความ + ปุ่ม CTA ซ้าย · คอลลาจ 3 รูปขวา)
**เปลี่ยนเป็นเปิดหน้าด้วยภาพล้วนเต็มความกว้างจอ** ไม่มีข้อความหรือปุ่มทับบนภาพเลย

| | ค่า |
|---|---|
| ความสูง | 520px · 420 (≤1080) · 320 (≤820) · 250 (≤560) |
| ภาพ | `public/assets/banner-mock-wide.jpg` — **1 ภาพ ไม่ใช่สไลด์** (ต่างจาก Concept B) |
| ข้อความ | ไม่มีเลย เนื้อหาที่เคยอยู่บน hero ย้ายลงมาเป็นบล็อกแนะนำจัดกลางใต้แบนเนอร์ |

### 🔧 วิธีเปลี่ยนเป็นแบนเนอร์จริง

1. เอาไฟล์จริงมาทับ `public/assets/banner-mock-wide.jpg`
   **สัดส่วนแนะนำ 2400 × 650 px** (แบนเนอร์กินเต็มความกว้างจอ อัตราส่วนกว้างกว่าของ Concept B)
   — เนื้อหาสำคัญให้อยู่กลางภาพ ขอบบน/ล่างจะโดน `object-fit:cover` ตัดเมื่อจอแคบ
2. ลบ `<span class="mock-tag">…</span>` 1 บรรทัดออกจาก `index.html` และลบ CSS `.mock-tag{…}`

> ถ้าอยากให้ Concept C เป็นสไลด์เหมือน B บอกได้ ใช้โค้ดสไลด์ชุดเดียวกันได้เลย

## ที่ยังไม่ได้ทำ

- ทำเฉพาะหน้า Home ลิงก์ทั้งหมดชี้ `#` หรือ anchor ในหน้า
- ยังไม่มีฟอร์ม (ใช้ LINE / โทร / อีเมล)
- ยังไม่ได้ทำ SEO metadata / JSON-LD

## ตรวจแล้ว

- Desktop 1920px · Tablet 820px · Mobile 430px — `scrollWidth` = `clientWidth` ทุกขนาด ไม่มี horizontal overflow
- ตัวกรองหมวดสินค้าในไซด์บาร์กดสลับได้จริง (บนมือถือยุบเป็นชิปแถวเดียว)
- กริดผลงานเต็มพอดี 4 แถว ไม่มีช่องโหว่ (`grid-auto-flow:dense`)
- เมนู hamburger + แถบ CTA ล่างจอมือถือทำงาน
- รูปโหลดครบ ไม่มี broken image

## ปรับตามฟีดแบ็กลูกค้า (รอบ "ฟ้าเข้มเกินไป")

พาเลตต์สีน้ำเงินอ่อนลงและลดความอิ่มสีทั้งชุด — ยังผ่านเกณฑ์ contrast ทุกจุด

| ตัวแปร | เดิม | ใหม่ |
|---|---|---|
| `--navy-950` (footer) | `#0b2135` | `#20404f` |
| `--navy-900` (แถบเข้ม) | `#0f2f4a` | `#2a5068` |
| `--navy-800` (หัวข้อ) | `#143d5c` | `#33607c` |
| `--blue-700` (ปุ่มหลัก) | `#1f5785` | `#3a6f92` |
| `--blue-600` | `#256da4` | `#4a86ab` |
| `--blue-500` | `#3488c1` | `#6aa4c4` |
| `--blue-300` (เส้น/ขอบ) | `#8ec4e5` | `#b3d7ea` |
| `--blue-100` | `#dcedf8` | `#e5f1f8` |
| `--sky` (พื้นอ่อน) | `#eaf4fc` | `#f1f7fb` |

พร้อมกับเปลี่ยน `rgba()` สีน้ำเงินเข้มที่เขียนตรง ๆ ในไฟล์ (เงาทับภาพ, เส้นคั่น) ให้ตรงกับพาเลตต์ใหม่

ตรวจ contrast กับตัวอักษรขาว — ปุ่มหลัก 5.4:1 · แถบเข้ม 8.6:1 · หัวข้อบนพื้นขาว 6.8:1 ผ่าน WCAG AA ทั้งหมด
