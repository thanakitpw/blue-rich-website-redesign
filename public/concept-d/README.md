ไฟล์เดียวจบ: `index.html` (HTML + CSS + JS ฝังในไฟล์ ไม่ต้อง build ไม่ต้องลง dependency)
เปิดดูได้ 2 ทาง

- ดับเบิลคลิกไฟล์เปิดในเบราว์เซอร์ได้เลย

รูปทั้งหมดอ้างอิงแบบ relative ไปที่ `../assets/` จึงใช้ได้ทั้งสองวิธี

## สีและฟอนต์

- **พาเลตต์เดิมทั้งชุด** — คัดลอกค่าตัวแปรจาก Concept B/C มาตรง ๆ ไม่มีการเปลี่ยนเฉดใด ๆ
  (`--navy-950 #20404f` … `--blue-100 #e5f1f8`, `--sky #f1f7fb`)
- **น้ำเงินเป็นสีหลัก** — ปุ่ม CTA, ขีดหัวข้อ, ไอคอน, ชิป, ลิงก์ ใช้ `--blue-700` / `--navy-800` ทั้งหมด
- **ส้ม `--flame` ใช้เฉพาะ 3 จุด** ตามกฎ design system เดิม
  1. ปุ่ม "ขอใบเสนอราคา" บนแถบเมนู (จุดเดียวในหน้าที่ต้องเด่นที่สุด — ตาม ref)
  2. แบดจ์ "สินค้าเรือธง / ขายดี" และเลข 2 ในไดอะแกรม (ชั้นสีกันไฟ)
  3. ค่าที่สื่อถึงไฟ/อุณหภูมิ — "ทนไฟ 1–3 ชม.", "550°C", "3 ชม."
- **ฟอนต์ Prompt** ทั้งหน้า (ชุดเดียวกับ B และ C)

## ไดอะแกรมภาคตัดขวาง (ของใหม่ใน D)

SVG เขียนมือในไฟล์ ไม่ใช่รูปภาพ — แก้สี/ข้อความได้จาก HTML ตรง ๆ
แสดงชั้นสีจากบนลงล่าง: สีทับหน้า → สีกันไฟ (พองตัว) → สีรองพื้น → เนื้อเหล็ก
พร้อมลูกศรความร้อนด้านบนและเส้นบอก "เนื้อเหล็กต้องไม่ถึง 550°C"

> **สัดส่วนความหนาในภาพไม่ใช่สเกลจริง** — เขียนกำกับไว้ใต้ภาพแล้ว เพื่อไม่ให้เข้าใจผิดว่าเป็นแบบก่อสร้าง

## ⚠️ ข้อความที่ยังต้องให้ลูกค้ายืนยัน

ยกชุดเดียวกับ Concept B/C มา บวกของใหม่ในหน้านี้

- **"15+ ปีประสบการณ์งานสีกันไฟ"** — แต่งเอง
- **"จันทร์ – เสาร์ 08:00 – 17:30 น."** — แต่งเอง
- **คำตอบ FAQ ทั้ง 5 ข้อ** — เขียนจากข้อมูลสินค้าจริง + ความเข้าใจงานสีกันไฟทั่วไป ควรให้วุฒิวิศวกรตรวจก่อน publish
- **สเปคใต้การ์ดผลงาน** (ระบบที่ใช้ / วิธีทำงาน / อัตราทนไฟ) — **เป็นข้อมูลตัวอย่างล้วน** ใส่ไว้ให้เห็นเลย์เอาต์แบบ ref
  มีหมายเหตุกำกับไว้ใต้ carousel ในหน้าแล้ว **ต้องเปลี่ยนเป็นข้อมูลโครงการจริงก่อนใช้งาน**
- **บทความ 2 เรื่องท้าย** ("เตรียมผิวเหล็กก่อนทาสีกันไฟ" และ "สีสะท้อนความร้อนใต้หลังคา") — หัวข้อแต่งขึ้นเพื่อเติมกริด 6 ช่องตาม ref
  ยังไม่มีบทความจริง ต้องเปลี่ยนหรือเขียนเพิ่ม
- **ไม่ได้ใส่ราคาและรหัสสินค้า** — ref มีทั้งสองอย่าง แต่ยังไม่มีข้อมูลจริง จึงใช้ "สอบถามราคา" แทนราคา
  และไม่สมมติ SKU ขึ้นมาเหมือน Concept B (ถ้าลูกค้ามีรหัสจริง ใส่เพิ่มในการ์ดได้ทันที)

## สิ่งที่ยังไม่ได้ทำ

- ลิงก์ทุกอันชี้ `#` หรือ anchor ในหน้า ยังไม่มีหน้าย่อย
- ยังไม่ได้ทำ SEO metadata / JSON-LD / sitemap
- ยังไม่มีฟอร์มติดต่อ (ตาม ref ที่ใช้ LINE + โทรอย่างเดียว)
- ถ้าลูกค้าเลือกแบบนี้ ค่อยแปลงเป็น Next.js component ทีหลัง
