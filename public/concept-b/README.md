## แบนเนอร์สไลด์ (เพิ่มใหม่)

อยู่บนสุดของหน้า เหนือหัวข้อ H1

| | ค่า |
|---|---|
| ความสูง | **550px** (desktop) · 430px (≤1024) · 300px (≤760) · 240px (≤430) |
| จำนวนสไลด์ | 3 · **ภาพล้วน ไม่มีข้อความ** |
| เลื่อนอัตโนมัติ | ทุก 6 วินาที · หยุดเมื่อเอาเมาส์ชี้หรือโฟกัสปุ่ม |
| ควบคุม | ลูกศร ‹ › มุมขวาล่าง + จุดบอกสไลด์มุมซ้ายล่าง (กดเลือกได้) |
| Accessibility | `aria-roledescription="carousel"` · ปิด autoplay ให้อัตโนมัติเมื่อผู้ใช้ตั้ง `prefers-reduced-motion` |

### ภาพล้วน ไม่มีข้อความทับ

ลูกค้าไม่อยากให้เปิดหน้ามาด้วยการขายสินค้า จึง **ถอดหัวข้อ คำโปรย และปุ่ม CTA ออกจากสไลด์ทั้งหมด**
เหลือแค่ภาพ + จุดบอกสไลด์ + ลูกศร (เงาไล่สีทับเหลือแค่ขอบล่างบาง ๆ เพื่อให้จุดกับลูกศรอ่านออก)

ข้อความที่เคยอยู่บนสไลด์ถูกตัดทิ้ง ไม่ได้ย้ายไปไหน — หัวข้อ H1 ของหน้าอยู่ใต้แบนเนอร์อยู่แล้ว

### 🔧 วิธีเปลี่ยนเป็นแบนเนอร์จริง

รูปตอนนี้เป็น **mockup** — `public/assets/banner-mock-1.jpg` … `-3.jpg`
(ไล่สีโทนแบรนด์ + ภาพหน้างานจาง ๆ ไม่มีตัวหนังสือฝังในภาพ)

1. เอาไฟล์แบนเนอร์จริงมาทับ `banner-mock-1.jpg` … `-3.jpg`
   **สัดส่วนแนะนำ 1600 × 746 px** (2.145:1 ตรงกับกล่องสไลด์ 1180 × 550)
   — อย่าฝังข้อความสำคัญไว้ริมซ้าย/ขวา เพราะ `object-fit:cover` จะตัดขอบเมื่อจอแคบลง
2. ลบ `<span class="mock-tag">…</span>` 1 บรรทัดออกจาก `index.html` (ป้าย MOCKUP มุมขวาบน)
   และลบ CSS `.mock-tag{…}` ถ้าอยากเก็บไฟล์ให้สะอาด
3. ถ้าอยากใส่ข้อความกลับเข้าไปบนสไลด์ทีหลัง บอกได้ — เดิมทำไว้เป็น HTML ไม่ได้ฝังในรูป

ไฟล์ mockup ตอนนี้ทำจากภาพหน้างานจริงของลูกค้า ปรับแสง/คอนทราสต์เล็กน้อย ขนาด 1400 × 652 px

## สิ่งที่ยังไม่ได้ทำ (เพราะทำเฉพาะหน้า Home ตามที่สั่ง)

- ลิงก์ทุกอันชี้ `#` หรือ anchor ในหน้า ยังไม่มีหน้าย่อย
- ยังไม่มีฟอร์มติดต่อ (Ref ก็ไม่มี ใช้ LINE + โทรอย่างเดียว)
- ยังไม่ได้ทำ SEO metadata / JSON-LD / sitemap
- ถ้าลูกค้าเลือกแบบนี้ ค่อยแปลงเป็น Next.js component ทีหลัง

## ตรวจแล้ว

- Desktop 1920px — ไม่มี horizontal overflow (`scrollWidth` = `clientWidth`)
- แบนเนอร์สไลด์: ทดสอบกว้าง 390 / 430 / 640 / 820 / 1920px — เนื้อหาสไลด์ไม่ล้นกรอบทุกขนาด
  ปุ่มลูกศรและจุดเลือกสไลด์ทำงาน สลับสไลด์ถูกต้อง
- Mobile 430px — ไม่มี overflow, เมนู hamburger, แถบ CTA ล่างจอ (LINE / โทร / ขอราคา) ทำงาน
- รูปทุกไฟล์โหลดได้ครบ ไม่มี broken image

## ปรับตามฟีดแบ็กลูกค้า (รอบ "ฟ้าเข้มเกินไป")

พาเลตต์สีน้ำเงินอ่อนลงและลดความอิ่มสีทั้งชุด — ยังผ่านเกณฑ์ contrast ทุกจุด

| ตัวแปร | เดิม | ใหม่ |
|---|---|---|
| `--navy-950` (footer) | `#0b2135` | `#20404f` |
| `--navy-900` (แถบเข้ม) | `#0f2f4a` | `#2a5068` |
| `--navy-800` (หัวข้อ) | `#143d5c` | `#33607c` |
| `--blue-700` (ปุ่มหลัก) | `#1f5785` | `#3a6f92` |
| `--blue-600` | `#256da4` | `#4a86ab` |
| `--blue-500` | `#3488c1` | `#6aa4c4` |
| `--blue-300` (เส้น/ขอบ) | `#8ec4e5` | `#b3d7ea` |
| `--blue-100` | `#dcedf8` | `#e5f1f8` |
| `--sky` (พื้นอ่อน) | `#eaf4fc` | `#f1f7fb` |

พร้อมกับเปลี่ยน `rgba()` สีน้ำเงินเข้มที่เขียนตรง ๆ ในไฟล์ (เงาทับภาพ, เส้นคั่น) ให้ตรงกับพาเลตต์ใหม่

ตรวจ contrast กับตัวอักษรขาว — ปุ่มหลัก 5.4:1 · แถบเข้ม 8.6:1 · หัวข้อบนพื้นขาว 6.8:1 ผ่าน WCAG AA ทั้งหมด
